# DAX

DAX (Data Analysis Expressions) is the formula language used by Power BI.

It allows you to create:

- Measures
- Calculated Columns
- Calculated Tables
- Advanced Analytics

## Core Concepts

### Measures

Measures calculate values dynamically based on filter context.

Example:

```sql
Total Sales =
SUM(Sales[Amount])
