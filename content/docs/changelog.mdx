# Changelog

A running record of meaningful additions and fixes to the Power BI content on this site. Site design, theming, and infrastructure changes aren't tracked here.

---

## 2026-08-04

- Added [Row-Level Security](/docs/power-bi-service/security) — static vs. dynamic RLS, `USERPRINCIPALNAME()`-based dynamic security, and common mistakes.
- Added [DirectQuery vs. Import](/docs/modeling/storage-modes) — storage modes, composite models, and when to use each.
- Added [Bookmarks & Interactivity](/docs/visuals/bookmarks) — bookmarks, drill-through, and report page tooltips.
- Added the remaining Power BI Service pages: [Workspaces](/docs/power-bi-service/workspaces), [Dashboards](/docs/power-bi-service/dashboards), [Refresh](/docs/power-bi-service/refresh).
- Added the remaining Visuals pages: [Charts](/docs/visuals/charts), [Tables](/docs/visuals/tables), [Slicers](/docs/visuals/slicers), [Formatting](/docs/visuals/formatting).
- Added the remaining DAX Patterns pages: [Totals](/docs/dax-patterns/totals), [Ranking](/docs/dax-patterns/ranking), [Percent of Total](/docs/dax-patterns/percent-of-total), [Running Total](/docs/dax-patterns/running-total).
- Added [Calculated Tables](/docs/dax/calculated-tables), the remaining Power Query pages ([Introduction](/docs/power-query/introduction), [Transformations](/docs/power-query/transformations), [Query Folding](/docs/power-query/query-folding)), and the remaining Getting Started pages ([Installation](/docs/getting-started/installation), [Power BI Overview](/docs/getting-started/power-bi-overview)).
- Fixed several DAX and Power Query code examples that were mislabeled as SQL, which gave them incorrect syntax highlighting.

## 2026-08-03

- Fixed stray leftover text and formatting issues in the Power Query content.
