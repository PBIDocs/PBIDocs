# Microsoft Fabric

Microsoft Fabric is the unified data platform Power BI now sits inside — one shared lake (OneLake) underneath Lakehouses, Warehouses, pipelines, and the semantic models that report on top of them.

```text
OneLake (one shared lake for the whole tenant)
     |
     +-- Lakehouse / Data Warehouse (store and transform data)
     +-- Data Factory (Pipelines, Dataflows Gen2)
     |
     | Direct Lake
     |
Power BI Semantic Model
```
