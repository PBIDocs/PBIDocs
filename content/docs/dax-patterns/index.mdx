# DAX Patterns

A handful of calculation shapes show up in nearly every Power BI report — totals that ignore filters, rankings, percent-of-total breakdowns, and running totals. This section covers the standard pattern for each one, ready to adapt. For systems and program engineering reports specifically, it also covers the standard Earned Value Management (CPI, SPI, EAC) metric set.
